BREAKOUT - Unity project

Open this FinalBuild folder in Unity Hub using Unity 6000.3.11f1.
Open Assets/Scenes/Breakout.unity, then press Play.
If the scene is missing, choose Breakout > Create or open game scene.

Move: A/D or Left/Right arrows, or hold the left mouse button.
Launch: Space. Pause/resume: Escape. Restart: R.
Break all 50 blocks to win. Missing the ball costs one of three lives.
The paddle hit position controls the rebound direction.

Export: Breakout > Build Windows game.
Run Builds/Windows/Breakout.exe. Keep the entire Windows output folder
together when sharing the game, including Breakout_Data and UnityPlayer.dll.

The court, paddle, ball, blocks, and HUD are generated at runtime.
No external art or starter package import is required.
